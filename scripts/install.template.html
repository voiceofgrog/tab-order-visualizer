1Tab-Order Visualizer

See how the Tab key moves through any page

A free bookmarklet that numbers every stop the Tab key visits, draws the path between them, flags order problems with plain-language fixes, and estimates how long keyboard and screen reader users take to get around.

How to use it

  1. Open the page you want to check, then click the Tab order bookmark.
  2. Read the badges and arrows on the page. The panel in the corner lists issues and lets you switch to the suggested order, step through stops, change colours and size, or pick an element to time.
  3. Keyboard users: focus moves to the panel when it opens. Alt+Shift+T moves between the page and the panel, and Esc returns to the page.
  4. Changed something on the page, such as opening a menu? Press Refresh. Click the bookmark again to close.

Why Tab order matters

Many people never use a mouse. They move through a page with the Tab key, often with a screen reader reading each stop aloud. When the order jumps around, skips things, or lands on something invisible, the page becomes confusing or impossible to use. WCAG 2.2 covers this under 2.4.3 Focus Order and related success criteria.

This tool makes the order visible, so editors and developers can catch problems before their users do.

Privacy and limits

Private by design

  • Runs entirely in your browser.
  • Sends nothing anywhere: no network requests, no analytics, no tracking.
  • Stores nothing, and changes nothing on the page apart from its own overlay.

Good to know

  • It is not proof of accessibility. Automated checks catch only some problems, so also test with a keyboard and a screen reader.
  • Some sites block bookmarklets. If nothing happens, use the browser extension version.{{EXTENSION}}
  • To stay small, the bookmarklet leaves out the extra axe-core checks that the extension includes.
  • Time estimates are a model, not a measurement.
